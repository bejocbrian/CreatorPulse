## Organizations

### What is an Organization?

An organization is a workspace where you can:
- Manage checklists and documents
- Collaborate with team members
- Track usage and manage subscriptions
- Control access and permissions

### Creating an Organization

1. Navigate to Organizations
2. Click "Create Organization"
3. Enter organization name
4. Choose a subscription plan
5. Complete setup

### Organization Roles

**Owner:**
- Full access to all features
- Can manage billing and subscriptions
- Can add/remove members
- Can delete organization

**Admin:**
- Can manage checklists and documents
- Can invite members
- Cannot manage billing

**Member:**
- Can create and edit checklists
- Can upload and view documents
- Limited administrative access

## Subscription Plans

### Plan Tiers

#### FREE (No Credit Card Required)
- **Documents**: 10
- **Storage**: 100 MB
- **Active Checklists**: 5
- **Team Members**: 3
- **Support**: Community

Perfect for individuals or small projects getting started.

#### STARTER ($29/month)
- **Documents**: 100
- **Storage**: 1 GB
- **Active Checklists**: 50
- **Team Members**: 10
- **Support**: Email

Great for small teams and growing businesses.

#### PROFESSIONAL ($99/month)
- **Documents**: 1,000
- **Storage**: 10 GB
- **Active Checklists**: 500
- **Team Members**: 50
- **Support**: Priority Email + Chat

Ideal for established businesses with larger needs.

#### ENTERPRISE (Custom Pricing)
- **Documents**: Unlimited
- **Storage**: Unlimited
- **Active Checklists**: Unlimited
- **Team Members**: Unlimited
- **Support**: Dedicated Account Manager
- **Custom Features**: API access, SSO, SLA

For large organizations with specific requirements.

### Upgrading Your Plan

1. Go to **Subscription** in your dashboard
2. Click **Upgrade Plan**
3. Select desired plan
4. Enter payment information
5. Confirm upgrade

**Note:** Upgrades take effect immediately. You'll be charged a prorated amount for the remainder of your billing period.

### Downgrading Your Plan

1. Go to **Subscription** in your dashboard
2. Click **Manage Subscription**
3. Select **Change Plan**
4. Choose a lower tier
5. Confirm downgrade

**Note:** Downgrades take effect at the end of your current billing period.

### Canceling Your Subscription

1. Go to **Subscription**
2. Click **Cancel Subscription**
3. Choose to cancel immediately or at period end
4. Confirm cancellation

**Important:** 
- Canceling immediately stops access to paid features
- Canceling at period end maintains access until the end of your billing cycle
- You can reactivate before the end date

## Checklists

### Creating a Checklist

1. Click **New Checklist**
2. Enter checklist title
3. Add description (optional)
4. Add checklist items
5. Attach documents (optional)
6. Save checklist

### Checklist Items

Each checklist item can include:
- **Title**: Brief description of the task
- **Description**: Detailed instructions
- **Attached Document**: Link to relevant document
- **Checkbox**: Mark as complete

### Managing Checklists

**Edit Checklist:**
- Click on checklist name
- Make changes
- Save updates

**Complete Checklist:**
- Check all items
- Mark checklist as complete
- Checklist moves to completed section

**Archive Checklist:**
- Click three dots menu
- Select "Archive"
- Archived checklists don't count toward active limit

**Delete Checklist:**
- Click three dots menu
- Select "Delete"
- Confirm deletion (permanent)

### Checklist Status

- **Active**: In progress, counts toward limit
- **Completed**: All items checked, can be archived
- **Archived**: Not in active use, doesn't count toward limit

## Documents

### Uploading Documents

1. Go to **Documents**
2. Click **Upload Document**
3. Select file from computer
4. Add name and description
5. Click **Upload**

**Supported File Types:**
- PDF documents
- Images (JPG, PNG)
- Microsoft Office (Word, Excel, PowerPoint)
- Text files

**File Size Limits:**
- FREE: 10 MB per file
- STARTER: 25 MB per file
- PROFESSIONAL: 50 MB per file
- ENTERPRISE: 100 MB per file

### Organizing Documents

**Search Documents:**
- Use search bar to find documents by name
- Filter by date uploaded
- Sort by name or date

**Document Details:**
- Name
- Description
- Upload date
- File size
- File type
- Attached checklists

### Attaching Documents to Checklists

1. Open checklist
2. Click on checklist item
3. Click **Attach Document**
4. Select document from library
5. Save changes

### Deleting Documents

1. Go to document details
2. Click **Delete**
3. Confirm deletion

**Note:** Documents attached to active checklists will be unlinked but checklists remain.

## Usage Monitoring

### Dashboard Metrics

Your dashboard displays:
- **Documents Used**: Current count vs. limit
- **Storage Used**: Current usage vs. available
- **Active Checklists**: Current count vs. limit

### Usage History

View historical usage data:
1. Go to **Usage** tab
2. Select date range (7, 30, 90 days)
3. View charts and graphs
4. Export data (CSV)

### Notifications

Receive alerts when:
- 80% of any limit is reached
- 100% of limit is reached
- Subscription needs attention
- Payment fails

### Storage Management

To free up storage:
1. Delete unused documents
2. Archive completed checklists
3. Remove duplicate files
4. Upgrade plan for more storage

## Billing and Payments

### Payment Methods

Accepted payment methods:
- Credit cards (Visa, Mastercard, Amex)
- Debit cards
- Apple Pay / Google Pay (via Stripe)

### Billing Cycle

- **Monthly**: Charged on the same day each month
- **Annual** (10% discount): Charged once per year

### Invoices and Receipts

Access your invoices:
1. Go to **Billing**
2. View **Invoice History**
3. Download PDF receipts
4. Receipts are also emailed after payment

### Failed Payments

If payment fails:
1. You'll receive an email notification
2. Automatic retry in 3 days
3. Additional retry in 5 days
4. After 10 days, subscription suspended

To update payment method:
1. Go to **Billing**
2. Click **Update Payment Method**
3. Enter new card details
4. Save changes

### Refund Policy

- **First month**: Full refund within 14 days
- **Subsequent months**: Pro-rated refund for unused time
- **Contact support** for refund requests

## FAQ

### General Questions

**Q: Is my data secure?**
A: Yes, we use industry-standard encryption, secure AWS infrastructure, and regular security audits.

**Q: Can I export my data?**
A: Yes, you can export checklists and documents at any time.

**Q: What happens if I exceed my limits?**
A: You'll receive a notification and be prompted to upgrade. Creation of new items will be blocked until you upgrade or remove items.

### Account Questions

**Q: Can I change my email address?**
A: Yes, in account settings. You'll need to verify the new email.

**Q: I forgot my password. What do I do?**
A: Use the "Forgot Password" link on the login page.

**Q: Can I have multiple organizations?**
A: Yes, one user can belong to multiple organizations.

### Subscription Questions

**Q: Can I switch between monthly and annual billing?**
A: Yes, contact support to switch billing cycles.

**Q: What if I need more than the Enterprise plan offers?**
A: Contact sales for custom enterprise solutions.

**Q: Do you offer non-profit discounts?**
A: Yes, contact support with proof of non-profit status.

### Technical Questions

**Q: Which browsers are supported?**
A: Chrome, Firefox, Safari, and Edge (latest 2 versions).

**Q: Is there a mobile app?**
A: Not currently, but the web app is mobile-responsive.

**Q: Can I integrate with other tools?**
A: API access is available on Enterprise plans.

### Billing Questions

**Q: When will I be charged?**
A: On signup and then on the same day each month/year.

**Q: Can I get a receipt for tax purposes?**
A: Yes, receipts are emailed and available in the billing section.

**Q: Do prices include tax?**
A: Tax may be added based on your location.
